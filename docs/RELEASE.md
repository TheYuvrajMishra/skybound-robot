# v1.0-release notes

Skybound Robot Runway Assault v1.0: endless sky-bridge runner-shooter, procedural low-poly models, pure deterministic sim, gates (additive), boulder weapon upgrades, HUD/menus, /dev/models and /dev/anims viewers, showcase mode (?showcase=1).

Known limitations: remote snapshot is a single commit (connector limitation); local tags are the rollback points; audio is silent by default; render uses fixed-step positions per frame.
